# RestaurantIQ Web App MVP

A mobile-first restaurant analytics dashboard prototype.

## Stack
- Next.js App Router
- React + TypeScript
- Recharts
- Lucide icons

Next.js's current App Router is the recommended routing model for new applications. See the official docs: https://nextjs.org/docs/app

## Run
```bash
npm install
npm run dev
```
Open http://localhost:3000
